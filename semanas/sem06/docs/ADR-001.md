# ADR-001: Usar SQLite como banco de dados

## Status

Aceito

## Contexto

O Compasso é um sistema de time tracking desenvolvido em 4 semanas por uma equipe de 4 pessoas. Não temos infraestrutura de servidor, e o volume de registros é baixo e previsível.

## Decisão

Vamos usar SQLite, porque ele roda embutido na aplicação, sem servidor de banco para instalar ou administrar.

## Consequências

**Mais fácil:** setup imediato, sem servidor de banco para administrar.

**Mais difícil:** não escala para produção com múltiplos projetos. Aceitamos esse limite para este contexto.
