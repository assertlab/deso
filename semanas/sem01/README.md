# Semana 1 — O mundo além do código

**CIN0136: Desenvolvimento de Software · CIn-UFPE**

---

## Visão da semana

A primeira semana tem três objetivos: criar o tom certo para o semestre, situar cada aluno no ecossistema de desenvolvimento de software, e colocar as equipes em contato com os stakeholders. Nenhum código de produto é escrito ainda — toda a energia vai para entender o contexto, o processo e os compromissos, e para dar os primeiros passos no fluxo de trabalho ágil.

## Objetivos de aprendizagem da semana

Ao final desta semana, você deve ser capaz de:

1. Articular a diferença entre programar e desenvolver software
2. Identificar os principais papéis, atividades e artefatos do ecossistema de DS
3. Compreender como o semestre se organiza em ciclos ágeis baseados em sprints
4. Saber quem é o stakeholder do seu projeto e o que será construído
5. Ter participado da construção do backlog inicial com o parceiro e registrado o encontro

## Conexão com o restante do semestre

O que acontece esta semana define a qualidade do Sprint 0 inteiro. O backlog construído com o stakeholder é o ponto de partida para a formalização dos requisitos e a prototipagem das semanas seguintes, que por sua vez alimentam o fechamento de escopo do MVP. Uma descoberta mal feita na Semana 1 custa semanas de retrabalho depois.
